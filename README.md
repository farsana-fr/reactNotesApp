# 📝 Notes App

A simple and colorful Notes Application built with **React** and **React Bootstrap**. Users can create, view, and delete notes with different background colors for better organization.

## 🚀 Features

- 📌 Create new notes
- 🎨 Choose a background color for each note
- 👀 View notes in a dedicated view
- 🗑️ Delete notes
- 📱 Responsive and clean UI
- ⚛️ Built using React functional components and Hooks (`useState`)

## 🎯 How to Use

1. Click the **+** button.
2. Enter a title.
3. Enter a description.
4. Select a background color.
5. Click **Add**.
6. Click any note to view its full content.
7. Delete notes using the **Delete** button.

## 📚 Concepts Practiced

This project helped practice the following React concepts:

- Functional Components
- Component Composition
- Props
- State Management using `useState`
- Conditional Rendering
- Event Handling
- Controlled Components
- Rendering Lists with `map()`
